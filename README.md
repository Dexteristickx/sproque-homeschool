# Sproque Homeschool

**A modern homeschool management platform for the Sproque learning community.**

Live: [sproque-homeschool.vercel.app](https://sproque-homeschool.vercel.app)

---

## What It Does

Sproque Homeschool is a web platform built to support homeschooling families with structured learning management. It uses Firebase for real-time data and provides a clean, organised interface for managing curriculum and student progress.

---

## Tech Stack

| Layer | Tech |
|-------|------|
| Frontend | Vanilla JavaScript + Vite |
| Styling | Tailwind CSS |
| Database | Firebase Firestore |
| Deployed | Vercel |

---

## Run Locally

```bash
git clone https://github.com/Dexteristickx/sproque-homeschool
cd sproque-homeschool
npm install
npm run dev
```
